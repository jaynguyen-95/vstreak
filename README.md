# V Streak

Member mini-game concept for Vegas Club: visit streaks, collectible 3D badges, Lucky Spin and a rewards shop.

**Single-file app.** Everything (code, styles, brand icons, member cards) lives in `index.html`. No build step, no dependencies. Fonts load from Google Fonts.

## Features

- Daily, weekly and monthly visit streaks with VP multipliers and streak shields
- 38 badges in 7 families (streaks, limited edition, monthly, first times, moments, social, secret)
- 3D badges: drag to spin, double-tap to flip and see the date and serial number
- Vegas diamond fireworks on every unlock
- Lucky Spin wheel, collection milestones, V Points shop, gift wallet with QR codes
- 4 languages: English, Tiếng Việt, 한국어, 中文
- Demo mode: each tap on **Check in** simulates one club visit; progress is saved in the browser (reset from *How it works*)

## Run locally

Open `index.html` in a browser. That's it.

## Publish with GitHub Pages

1. Push this folder to a repository.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, branch `main`, folder `/ (root)`.
3. The page goes live at `https://<user>.github.io/<repo>/`.

## Notes

- All member data, prices and odds are sample values for the demo. Voucher codes have no cash value.
- Contains Vegas Club brand assets (member cards, gold icons, ruby diamond). Keep the repository **private** unless the brand team approves public use.

## Responsible play

Badges reward visits and experiences, never stakes or losses. Members can pause their streak at any time without losing badges.
